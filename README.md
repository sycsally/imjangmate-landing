# 임장메이트 랜딩페이지

경매·재테크 임장을 위한 AI 임장 기록 앱 **임장메이트**의 사전 신청 랜딩페이지입니다. 성과 대시보드는 별도 저장소 [imjangmate-admin](https://github.com/sycsally/imjangmate-admin)에 있습니다.

| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `main.js` | 랜딩페이지 |
| `track.js` | 조회·방문자·CTA·구매 버튼·신청·유입 경로 수집 |
| `config.js` | 데이터 수집 주소(ENDPOINT) 설정 |
| `apps-script/Code.gs` | 구글 시트에 데이터를 저장하는 백엔드 |

## 1. 데이터 수집 설정 (처음 한 번, 약 10분)

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다. 이름 예: `임장메이트 데이터`
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다
3. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 통째로 붙여 넣고 저장합니다
4. 왼쪽 ⚙️ **프로젝트 설정 → 스크립트 속성 → 속성 추가**
   - 속성: `ADMIN_KEY`
   - 값: 대시보드 비밀번호 (길고 추측하기 어렵게. 팀원끼리만 공유)
5. 편집기 위쪽 함수 목록에서 `setup`을 고르고 **실행** → 권한 승인 (시트에 `events`, `signups`, `config` 탭이 생깁니다)
6. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - 배포 후 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사
7. `config.js`의 `ENDPOINT: ""` 따옴표 안에 그 URL을 붙여 넣고 커밋 → Vercel이 자동 재배포

> `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영됩니다. URL은 그대로입니다.

## 2. 대시보드 보기 (제작자 전용)

- 대시보드는 [imjangmate-admin](https://github.com/sycsally/imjangmate-admin) 저장소에 있고, 랜딩과 다른 주소로 배포합니다. 설정 방법은 그 저장소 README 참고
- 대시보드 `config.js`에도 같은 `ENDPOINT`를 넣고, `ADMIN_KEY` 비밀번호로 로그인합니다
- 원본 데이터는 본인 구글 시트에만 있고, 시트는 공유하지 않는 한 다른 사람이 볼 수 없습니다
- 팀원 본인 접속을 통계에서 빼려면 기기마다 한 번 랜딩 주소 뒤에 `?internal=1`을 붙여 접속합니다

## 3. 대시보드에 나오는 지표

### ① 랜딩페이지
| 지표 | 정의 |
|---|---|
| **KPI 가설 (XYZ)** | “랜딩페이지 방문자(Y)의 10%(X)는 출시 알림을 위해 연락처를 남길 것이다(Z)” 외 2개. 목표 %는 대시보드에서 수정·저장 |
| 조회수 | 페이지가 열린 횟수 (`pageview`) |
| 방문자 수 | 브라우저별 고유 ID 수 |
| CTA 버튼 | 출시 알림 신청, 얼리버드 가격 보기, 가격별 ‘사전 예약하기’(구매 버튼) 클릭 수 |
| 전환 | 출시 알림 신청 완료 (중복 연락처 제외) |
| 유입 경로 | 광고 / 에브리타임 / 검색 / SNS·블로그 / 카페·커뮤니티 / 직접 유입 (UTM + referrer) |
| 퍼널 | 방문 → 스크롤 50% → CTA 클릭 → 폼 작성 시작 → 신청 |

### ② 광고
대시보드 ‘광고 성과’에 광고별 **노출 수·클릭 수·광고비**(광고 관리자 화면 숫자)를 입력하면 나머지는 자동 계산됩니다.

| 지표 | 계산 |
|---|---|
| CTR | 클릭 수 ÷ 노출 수 × 100 |
| CVR | 전환 수 ÷ 클릭 수 × 100 (전환 기준: 출시 알림 신청 또는 구매 버튼 클릭 중 선택) |
| CPC | 광고비 ÷ 클릭 수 |
| CPA | 광고비 ÷ 전환 수 |
| ROAS | 광고로 발생한 매출 ÷ 광고비 × 100 — 매출 = 해당 광고로 들어온 방문자가 누른 ‘사전 예약하기’ 가격 합 (방문자당 상품별 1회) |

## 4. 광고·게시글 링크 만들기 (중요)

유입 경로를 정확히 나누려면 광고·게시글마다 UTM이 붙은 링크를 씁니다. 대시보드의 **광고용 링크 만들기**에서 바로 만들 수 있어요.

```
에브리타임 유료 광고   ?utm_source=everytime&utm_medium=paid&utm_campaign=launch_1
에브리타임 무료 게시글 ?utm_source=everytime&utm_medium=post&utm_campaign=free_post
인스타그램 광고        ?utm_source=instagram&utm_medium=paid&utm_campaign=auction_reels
네이버 경매 카페 글    ?utm_source=naver_cafe&utm_medium=post&utm_campaign=auction_cafe
```

`utm_medium`이 `paid`·`cpc`·`ad` 등이면 **광고**로, `utm_source=everytime`이면서 광고가 아니면 **에브리타임**으로 분류됩니다. 광고 성과 표의 `utm_campaign` 칸에 같은 캠페인 이름을 넣어야 전환·매출이 연결됩니다.

## 개인정보

신청 폼은 연락처(휴대폰 또는 이메일)와 임장 관련 응답만 받고, 필수 동의를 받습니다. 신청자 데이터는 구글 시트 `signups` 탭과 비밀번호가 걸린 대시보드에서만 볼 수 있습니다. 시트를 다른 사람과 공유하지 마세요.
